3. Anwendung „GTA-Shorts Upload“

„GTA-Shorts Upload“ ist ein privates Werkzeug des Betreibers des YouTube-Kanals GTA-Shorts.Germany. Die Anwendung wird ausschließlich vom Kanalinhaber selbst für den eigenen Kanal genutzt. Es gibt keine Registrierung für andere Personen, und es werden keine Daten anderer Nutzerinnen und Nutzer verarbeitet.

Die Anwendung nutzt die offizielle YouTube Data API (YouTube API Services). Der Kanalinhaber erteilt dafür einmalig über den offiziellen Google-Anmeldedialog (OAuth 2.0) seine ausdrückliche Zustimmung. Mit dieser Zustimmung:

  • lädt die Anwendung selbst erstellte Kurzvideos (YouTube Shorts) auf den eigenen Kanal des Inhabers hoch,
  • setzt Titel, Beschreibung (mit Quellenangaben), Schlagwörter und den geplanten Veröffentlichungszeitpunkt,
  • prüft vor jedem Upload anhand der eigenen bisherigen Uploads, dass kein Video doppelt hochgeladen wird,
  • kann geplante, noch nicht veröffentlichte Videos auf Wunsch des Inhabers wieder auf „privat“ setzen (Not-Aus).

Die Anwendung löscht keine Videos, liest keine Kommentare, Nachrichten oder Zuschauerdaten, nutzt keine Analyse- oder Umsatzdaten und greift auf keine anderen Google-Dienste (z. B. Gmail, Drive, Kontakte) zu.

Durch die Nutzung der YouTube API Services gilt zusätzlich die Datenschutzerklärung von Google.

5. Schutz der OAuth-Zugangsdaten

  • Client-ID, Client-Schlüssel und Refresh-Token werden ausschließlich als verschlüsselte GitHub-Actions-Secrets im privaten Repository des Inhabers gespeichert – niemals im Quellcode, in Dateien des Repositorys, auf dieser Website oder in Protokollen.
  • GitHub speichert Secrets verschlüsselt und schwärzt sie automatisch in Ausführungsprotokollen.
  • Kurzlebige Zugriffstokens werden nur während eines Laufs im Arbeitsspeicher gehalten und nicht gespeichert.
  • Die Kommunikation mit Google erfolgt ausschließlich verschlüsselt über HTTPS mit den offiziellen Google-Bibliotheken.
  • Uploads erfolgen nur, wenn der Inhaber die Automatik ausdrücklich eingeschaltet hat und der verbundene Kanal mit der hinterlegten Kanal-ID übereinstimmt. Ein Not-Aus-Schalter stoppt alle Uploads sofort.

6. Speicherdauer

  • Refresh-Token und Client-Daten: bis der Inhaber den Zugriff widerruft oder die Secrets löscht. Google macht ein Refresh-Token zusätzlich ungültig, wenn es sechs Monate nicht genutzt oder der Zugriff im Google-Konto entfernt wird.
  • Upload-Protokoll (Video-ID, selbst erstellter Titel, geplanter Zeitpunkt, Prüfergebnisse): im privaten Repository des Inhabers, solange es zur Vermeidung doppelter Videos benötigt wird; der Inhaber kann es jederzeit löschen.
  • Erstellte Videodateien als Zwischenergebnis der Produktion: werden in GitHub Actions nach 7 Tagen automatisch gelöscht.

8. Zugriff widerrufen

Der Zugriff der Anwendung auf das Google-/YouTube-Konto kann jederzeit widerrufen werden:

  1. Die Seite Google-Konto → Sicherheit → Drittanbieter-Zugriff öffnen (alternativ myaccount.google.com/connections).
  2. „GTA-Shorts Upload“ auswählen und Zugriff entfernen.

Danach kann die Anwendung nicht mehr auf den Kanal zugreifen. Bereits auf YouTube veröffentlichte Videos bleiben bestehen und können in YouTube Studio verwaltet werden.

10. English summary

“GTA-Shorts Upload” is a private tool used only by the owner of the YouTube channel GTA-Shorts.Germany for that same channel. With the channel owner’s explicit consent via Google OAuth 2.0 (scope https://www.googleapis.com/auth/youtube), it uses the YouTube Data API to upload self-produced Shorts to the owner’s own channel, set titles, descriptions and scheduled publishing times, check the owner’s own uploads to prevent duplicates, and set scheduled videos back to private on request. It does not delete videos and does not access comments, messages, analytics or other Google services.

OAuth credentials are stored only as encrypted GitHub Actions secrets, never in source code, files, logs or on this website; access tokens are kept in memory only. Data obtained from Google APIs is not sold, not used for advertising, not used to train AI models and not shared with third parties except Google/YouTube and GitHub as required for operation. GTA-Shorts Upload’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google Account security settings. See also the Google Privacy Policy. Contact: {{EMAIL}}.
